🔑 API ربات خارجی

راهنمای سازندگان ربات

Base URL: https://ariax-1.onrender.com

این API فقط برای AriaX Testnet است. ابتدا کلید و Secret را بسازید و آن‌ها را در متغیر محیطی ربات نگه دارید؛ Secret را در کد، GitHub یا تصویر منتشر نکنید.

احراز هویت

در تمام درخواست‌های خصوصی این دو Header را ارسال کنید:

X-API-Key: ARX_KEY
X-API-Secret: ARX_SECRET
Content-Type: application/json
دریافت داده
  • GET /api/markets — قیمت‌های لحظه‌ای و وضعیت منبع
  • GET /api/wallet — موجودی و مارجین آزاد
  • GET /api/orders — سفارش‌های باز
  • GET /api/positions — پوزیشن‌ها، PnL و قیمت لیکوئید
  • GET /api/fills — تاریخچهٔ اجرای معاملات و کارمزد
  • GET /api/performance — سود/زیان تحقق‌یافته، کارمزد و سود خالص
ارسال سفارش
POST /api/order
{"symbol":"ETHUSD","side":"buy","type":"market","qty":0.01,"lev":5}

برای سفارش Limit، type را limit و price را هم ارسال کنید. نمادهای فیوچرز: BTCUSD، ETHUSD، SOLUSD، XRPUSD، DOGEUSD، ADAUSD، AVAXUSD، LINKUSD، DOTUSD، LTCUSD، BCHUSD، TRXUSD، XLMUSD، AAVEUSD و UNIUSD.

بستن پوزیشن

برای بستن لانگ، سفارش sell و برای بستن شورت، سفارش buy با همان qty پوزیشن بفرستید. قبل از آن GET /api/positions را بخوانید.

POST /api/order
{"symbol":"ETHUSD","side":"sell","type":"market","qty":0.01,"lev":5}
لغو سفارش
POST /api/cancel
{"id":123}
نمونهٔ Python
import os, requests
BASE = "https://ariax-1.onrender.com"
h = {"X-API-Key": os.environ["ARIAX_KEY"],
     "X-API-Secret": os.environ["ARIAX_SECRET"]}
r = requests.post(BASE + "/api/order", headers=h, json={
  "symbol":"ETHUSD", "side":"buy", "type":"market",
  "qty":0.01, "lev":5})
print(r.json())

کارمزد: میکر ۰٫۰۲٪ و تیکر ۰٫۰۵٪ است. پاسخ API را پیش از سفارش بعدی بررسی کنید، حجم را با minq/step موجود در /api/config معتبر کنید و روی خطای شبکه سفارش را کورکورانه تکرار نکنید.
