## 🏗 معماری تیم ۶گانه

| تیم | ماژول | وظیفه |
|---|---|---|
| ۱ اتصال | `AriaXAPI` | کلاینت مقاوم: retry با backoff، احراز هویت دوگانه (legacy + Bybit v5)، گارد سلامت با پیام فارسی |
| ۲ داده | `klines()` | کندل از خود صرافی (Kraken) → fallback عمومی OKX/Bybit/Binance |
| ۳ بک‌تست | `local_backtest` + `select_strategies` | بازپخش ۴ استراتژی روی داده واقعی، امتیاز = بازده − ۰.۵×افت سرمایه، برنده هر نماد |
| ۴ استراتژی | `Strategies` | `ema_cross / sma_cross / rsi_reversion / macd` + فیلتر روند ۱ ساعته + استاپ‌های ATR |
| ۵ ریسک | `Risk` | ریسک ۰.۷۵٪ هر معامله، حداکثر ۳ پوزیشن، سقف ۱۲۰$، R:R=1.67، ترمزهای DD/روزانه |
| ۶ مانیتورینگ | `Telegram` + داشبورد + `Journal` | کنترل کامل تلگرامی، وب‌داشبورد، دفترچه SQLite |

## 📜 چرخه کار

1. **بوت**: گارد سلامت → کانفیگ → شارژ خودکار کیف فیوچرز → انتخاب استراتژی هر نماد (بک‌تست)
2. **هر ۴۵ ثانیه**: اسکن همه نمادها؛ ورود فقط در «تغییر سیگنال» + هم‌جهتی روند ۱h
3. **پس از هر ورود**: بلافاصله `TP/SL` روی سرور صرافی قفل می‌شود (`/api/tpsl`)
4. **هر ۲۰ ثانیه**: همگام‌سازی با صرافی؛ پوزیشن بسته‌شده توسط SL/TP صرافی شناسایی و ثبت می‌شود؛ SL/TP بدون‌حفاظت دوباره مسلح می‌شود
